# WEEK 2 | FOOTPRINTING & RECONNAISSANCE

## Project Overview

This project focuses on **Footprinting, Reconnaissance, and Network Scanning** using various cybersecurity tools available in Kali Linux.

The objective of this project is to understand how information about a target organization or domain can be collected during the reconnaissance phase of a security assessment.

The project is divided into the following modules:

- **Module 1:** Footprinting & Reconnaissance Attacks with Multiple Kali Tools
- **Module 2:** Footprinting & Reconnaissance Attacks with GHDB
- **Module 3:** Footprinting & Reconnaissance Attacks with theHarvester
- **Module 4:** Network Scanning with Zenmap

### Tools Used

- WHOIS
- WhatWeb
- NSLookup
- cURL
- WAFW00F
- DNSRecon
- Google Hacking Database (GHDB)
- theHarvester
- Zenmap

### Objectives

The main objectives of this project are:

1. Understand the concept of footprinting and reconnaissance.
2. Collect publicly available information about an authorized target.
3. Identify domain registration and DNS information.
4. Identify web technologies used by a website.
5. Analyze HTTP response headers.
6. Detect the presence of a Web Application Firewall.
7. Perform DNS enumeration.
8. Understand Google Hacking Database techniques.
9. Use theHarvester to identify publicly available email addresses and subdomains.
10. Perform network scanning using Zenmap.

> **Ethical Note:** All reconnaissance and scanning activities should be performed only on systems for which proper authorization has been obtained.
