# FOOTPRINTING & RECONNAISSANCE ATTACKS WITH MULTIPLE KALI TOOLS

## Project Overview

This project focuses on **footprinting, reconnaissance, OSINT, and network scanning** using various cybersecurity tools available in Kali Linux.

The practical activities demonstrate how publicly available information can be collected during the reconnaissance phase and how network hosts can be discovered and visualized in a controlled environment.

The project includes practical exercises using tools such as **WHOIS, WhatWeb, NSLookup, cURL, WAFW00F, DNSRecon, theHarvester, and Zenmap**.

---

## Objectives

The main objectives of this project are:

* To understand the concepts of footprinting and reconnaissance.
* To gather publicly available information about a target domain.
* To understand and practice different reconnaissance techniques.
* To identify web technologies used by a website.
* To resolve domain names into IP addresses.
* To examine HTTP response headers.
* To identify Web Application Firewalls.
* To enumerate DNS records.
* To collect publicly available email IDs, hosts, and sub-domains using theHarvester.
* To perform network discovery using Zenmap.
* To identify live hosts and their IP and MAC addresses.
* To generate and visualize network topology.
* To gain practical experience using cybersecurity tools in Kali Linux.

# Modules

## Module 1 | Footprinting & Reconnaissance Using Multiple Kali Tools

This module demonstrates the use of multiple Kali Linux tools for performing basic footprinting and reconnaissance.

### Tools Used

* **WHOIS** – Used to obtain domain registration and ownership-related information.
* **WhatWeb** – Used to identify web technologies and frameworks used by a website.
* **NSLookup** – Used to resolve domain names into IP addresses.
* **cURL** – Used to examine HTTP response headers.
* **WAFW00F** – Used to identify the presence of a Web Application Firewall.
* **DNSRecon** – Used to enumerate DNS records associated with a domain.

### Tasks Covered

1. Run WHOIS to find domain registration details.
2. Run WhatWeb to fingerprint web technologies.
3. Run NSLookup to resolve the domain to an IP address.
4. Run cURL to read HTTP response headers.
5. Run WAFW00F to detect a Web Application Firewall.
6. Run DNSRecon to enumerate DNS records.

## Module 3 | Footprinting & Reconnaissance Using theHarvester

This module demonstrates the use of **theHarvester** for collecting publicly available information related to a target domain.

### Tasks Covered

* **Task 1:** Find email IDs and sub-domains using **Baidu** with a result limit of 1000.
* **Task 2:** Find email IDs and sub-domains using **all available sources** with a result limit of 50.

The information collected may include publicly available hosts, sub-domains, email addresses, IP addresses, and other reconnaissance information.

# Network Scanning | Zenmap

This section demonstrates the use of **Zenmap**, the graphical user interface for Nmap, for network discovery and topology visualization.

### Activities Covered

* Identifying the local IP address and subnet using the `ipconfig` command.
* Discovering live hosts on the local network.
* Identifying IP and MAC address information where available.
* Performing network scanning using Zenmap.
* Viewing discovered hosts in the **Topology** section.
* Enabling the topology legend.
* Saving the generated network topology in PDF format.

The network scanning activities were performed in a controlled and authorized environment.
